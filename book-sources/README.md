# Legado 书源

## 起点中文·官方免费

书源文件：`qidian-mobile-free.json`

这是一个自包含的起点中文网官方移动网页书源。它支持按书名搜索、书籍详情、完整目录，以及起点网页匿名公开的免费章节。需要订阅或只能在起点 App 中阅读的章节会标记为 VIP，不会尝试绕过访问限制。

### 导入

1. 在 Legado 3.x 打开“我的” -> “书源管理”。
2. 选择右上角菜单中的“本地导入”。
3. 选择 `qidian-mobile-free.json`。
4. 保持“起点中文·官方免费”启用，在搜索中输入书名，例如“斗破苍穹”。

### 当前验证结果

验证日期：2026-08-04

- 标准 JSON 解析：通过，文件是仅包含一个书源的可导入数组。
- Node 静态契约和起点官方实时端点回归：7 项测试全部通过。
- 验收关键词：`斗破苍穹`；原作书籍 ID `1209977`，作者“天蚕土豆”。
- 搜索：官方移动搜索页返回 20 条结果，并能生成原作详情地址。
- 详情：书名、作者、分类、状态、封面回退和目录地址解析通过。
- 目录：Legado Source Validator v2.1.1 HTTP 模式解析 1,681 个章节节点；`_unPay_` 节点按 VIP 处理。
- 正文规则：Node 实时回归提取的公开章节正文长度超过 1,000 字符；受限章节在 `vipStatus=1` 且 `isBuy=0` 时返回空。
- Validator 正文诊断：规则从两个官方章节分别提取 530 和 761 字符，但起点正常页面包含 WAF 引导变量 `x-waf-captcha-referer`，触发 Validator v2.1.1 的验证码启发式误报，因此官方直接 HTTP 全链路的最终状态仍是 `failed`，错误码为 `CONTENT_IS_CAPTCHA_PAGE`。
- 误报隔离复核：仅在临时内存诊断中移除上述 WAF 标记后，同一正文规则立即通过，详情、目录和正文阶段均为 `success`；该诊断代理不属于书源，也未写入仓库。
- Android/Legado 真机：本机当前无在线 adb 设备，尚未完成真机导入验证。

### 限制

- 只搜索起点中文网已收录的作品，不是多站聚合搜索。
- 只读取官方移动网页匿名公开的章节；订阅、App 专享、登录或验证码内容不在支持范围内。
- 起点页面结构或安全策略变化后，CSS 选择器或页面上下文路径可能需要维护。
- 不包含 Cookie、Token、账号信息、第三方代理或聚合正文接口。
- 当前没有 Android/Legado 真机验证证据；导入后如遇兼容问题，应以 Legado 实际调试日志为准。
- 仅供个人学习、兼容性验证和在服务条款允许范围内使用；不得用于内容再分发或规避平台限制。
